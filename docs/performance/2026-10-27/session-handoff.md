## Final decisions

The retained engine change comprises:

- In-place unique-key compaction in `terrainHeightPixels`: captured packing
  median 4.304 → 4.021 ms (6.6% less); unchanged control differs 0.3%.
- Ready lattice samples, exact corner positions and nearest-point-keyed hull
  spheres in `imagerySelector`: 30 balanced warm rounds improve the captured
  combined selector/measurement workload about 10.9% versus unchanged control.
  Numeric audit checks every coordinate/sphere with `Object.is`; the missing-key
  mutant fails that audit. Existing identity digests remain unchanged.
- Ordered single-pass binding collection and exact tile-key set equality in
  `createImageryRuntime`: two independent synthetic cohorts show repeatable
  savings in these operations, with the 16-page case inconclusive. No hashes,
  cadence changes, skipped measurements/publications or public API changes.

These isolated improvements are not FPS, memory-footprint or power claims.
Final combined browser results and source identities are stored in engine
`docs/performance/2026-10-27/browser-results.json`; all three changes share that
browser arm, so it cannot isolate their individual contributions.

combined node/page traversal, and the previous-insertion common-prefix cache.
